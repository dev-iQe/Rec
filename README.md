# iCerf - iOS Signing Tool

تطبيق توقيع وتثبيت تطبيقات iOS المكتمل بمُعرِّف `com.icerf.iq`.

## الميزات:
- واجهة كاملة بلغة SwiftUI
- إمكانية تحديد ملفات IPA و P12 و MobileProvision
- ملف بناء تلقائي عبر GitHub Actions للبناء مباشرة إلى ملف IPA
- رابط التثبيت المباشر (OTA) عبر ملف Manifest.
